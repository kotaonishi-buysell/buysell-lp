# Downsizing LP Design System

## 適用範囲と出典
この仕様は /downsizing のみに適用します。home-value や将来のLPへ自動適用しません。
既存実装（src/styles/tokens.css、base.css、fonts.css、src/components/）を基に、現在の見た目を文書化しています。リポジトリ外の元仕様書を復元したものではありません。

## 方向性
引越し・住み替えを考えている50〜70歳の生活者向け。落ち着いた紙色とセージの色面、読みやすい本文、セリフ体の大きな見出しを使います。
写真は朝の自然光の部屋、引越しの箱、思い入れのある品を想定します。高額買取をあおらず、価値を聞いてから選べる安心感を伝えます。

## 文字
- 見出し: Newsreader。フォールバックは Iowan Old Style、Georgia、serif。
- 本文・ボタン: Instrument Sans。フォールバックは Helvetica Neue、Arial、sans-serif。
- Newsreader は可変フォント、Instrument Sans は400・600を自前配信。public/fonts/ のライセンスを維持します。

| Hero H1 | 40 / 44px | 64 / 68px |
| H2 | 32 / 40px | 44 / 52px |
| H3 | 28 / 36px | 同左 |

| 本文 | 18 / 30px | 同左 |

見出しは基本400、H3は500、ラベル・ボタンは600。文字の役割は base.css の既存クラスに合わせます。

## 余白・形状
- 余白単位: 8、16、24、40、64、104px。
- コンテンツ最大幅: 1120px。本文幅: 640px。
- ページ左右余白: 24px、720px以上で40px。
- セクション上下余白: 64px、1024px以上で104px。
- 小さな角丸: 4px。カード・写真・FAQ・フォーム: 12px。ボタン: 999px。
- 最小タップ高: 56px。
- カード影: 0 1px 2px rgba(36,33,28,.06), 0 8px 24px rgba(36,33,28,.06)。

## 部品とレスポンシブ
- Hero はモバイルでコピー→写真、1024px以上で左右2列。写真比率は縦置き時4:3、左右配置時4:5。
- ChoiceCards は明るいカード背景、3枚。1024px以上で3列。
- CategoryGrid は明るい背景・細い境界線。720px以上で2列、1024px以上で3列。
- 訪問査定の流れは4段階。720px以上で2列、1024px以上で4列。
- FAQ は明るいパネルと区切り線のある details/summary。最初の質問は開いています。
- 最終CTAは scene-move。フォームは明るい独立パネル上に配置します。
- 主CTAは電話、補助CTAはオンラインフォーム。モバイルの主ボタンは全幅。
- スマホの追従電話バーはHero通過後に表示、最終CTA以降で非表示。

## アクセシビリティ・動き
- フォーカスリング: 2px、外側3px。明るい面では ink。
- キーボード操作、セマンティックHTML、スキップリンクを維持。
- FAQ等の短い動きは200ms。prefers-reduced-motion で動きを抑えます。

## 変更時
- このLPの仕様変更は本ファイルに記録します。
- tokens.css、base.css、共通部品を変更する場合は home-value への影響も確認します。
- 対象LPだけを変更するときは body[data-lp="downsizing"] で限定するか専用部品を使用します。
- 写真・会社情報・費用等の未確定値は既存TODO方式を維持します。
- home-value の仕様を理由に、このLPの配色・フォント・角丸を変更しません。
