# Gold LP 第2案（gold-v2）のデザイン

`/gold-v2` は、Figma で作られた Gold LP のデザイン（ファイル「バイセルUS_GOLD_LP」、**改修B案**のフレーム `SP_W390_B`、幅390px）を、`/gold` とは別に新しく作ったLPです。**`/gold` には一切手を入れていません。** 他のLPのデザインシステムは使いません。**見た目の正本は Figma と `src/styles/gold-v2.css` です。**

- Figma：ファイルキー `D9ezRBg2LGvlPx8KS3D7xY`、フレーム `4:393`（`SP_W390_B`、改修B案）。**2026-11-28 に、改修A案（フレーム `29:412`、茶色と金色）から、B案に替えた。** 構成と文言は A と同じで、違いは色と、写真5枚だけ（下の「色・書体」「写真」）。**ただし、ヘッダーの上の「Free in-home appraisals in Dallas–Fort Worth and Houston\*」の帯は、2026-11-28 に削除した**（Figma にはまだある。訪問エリアの案内は、ヒーローと「Areas」の節にある）。
- **検索には出しません**（2026-11-27 に、`/gold` を主のGold LPと決めた）。`gold-v2.ts` の `meta.noindex: true` で、`<meta name="robots" content="noindex, nofollow">` を出し、canonical は付けません（`Document.astro`）。URL を知っている人（広告やテストの宛先）は、これまでどおり開けます。`robots.txt` で塞がないこと（クローラーが noindex を読めなくなるため。`tests/gold-v2.test.mjs` が確認）。検索に戻すときは、`noindex` の行を消すだけです。
- **公開ページです**（`src/pages/gold-v2.astro`）。`/gold` とは別のページで、`/gold` は置き換えも変更もしていません。写真は `/gold` と同じ画像です（下の「写真」）。

## 画面幅ごとの見え方
Figma にはスマホ幅（390px）のデザインしかありません。そのため、**960px 未満は、スマホ版のまま、最大 430px の 1 列を中央に置きます**（`.g2-page`。390〜430px では伸縮し、それより広いタブレットでは、左右に背景色 `--outer` `#EFE8DA` が出ます）。

**960px 以上（PC）は、同じセクションを並べ直します**（2026-11-28 に追加。Figma の PC 版はなく、今のデザインの延長で作った）。`gold-v2.css` の末尾の、`@media (min-width:960px)` の 1 ブロックだけです。ほかに、画面幅で変わるルールは書きません（`tests/gold-v2.test.mjs` が確認します）。`/gold` の `--pc-zoom`（拡大）は使いません。

| セクション | PC の見え方 |
|---|---|
| 全体 | 幅いっぱい（最大 1600px）。中身は 1120px の列 |
| ヘッダー | ロゴ、ナビ、電話番号、「Get my free appraisal」のボタンを 1 行に。**画面の上に固定**（PC は追従バーがない代わり）。メニューのボタンとドロワーは出ない |
| ヒーロー | 左がチャコール地に文字、右が写真（幅 58%、左へ向けてチャコールに溶ける） |
| 手順 | 4 列 |
| Who we are | 左に写真、右に文字 |
| What we buy | カルーセル → 4 列のグリッド（7枚。最後の段は中央）。前へ・次へのボタンは出ない |
| 安心の 4 つ | 4 列 |
| 訪問エリア | 2 つのカードを横に |
| FAQ | 幅 760px で中央 |
| 申込み | 左に見出しと電話、右にフォーム（共通フォームの幅だけ変える） |
| フッター | ブロックを横に並べる |
| 追従バー | 出さない（`display:none`）。スマホ（960px 未満）だけ |

- ヘッダーの電話番号とボタン（`.g2-hd-tel-n`、`.g2-hd-cta`）は、スマホでは隠します。HTML は 1 つで、見た目を CSS で切り替えます。
- ヘッダーと、ナビは、`.g2-top` で包んでいます。PC では、`.g2-hd` を `display: contents` にして、同じ行に並べます。
- 品目のカードのスクロール枠（`.g2-car-vp`）は、PC ではスクロールしないため、`gold-v2.ts` が、キーボードの停止点（`tabindex`）を外します。
- ヒーローの写真（1080px 幅）は、PC では約 750px 幅で表示するので、荒くなりません。ただし、1600px を超える画面は、背景色に切り替わります。

## 実装
- ページ：`src/pages/gold-v2.astro`、レイアウト：`src/layouts/GoldV2Layout.astro`（`base.css`、`silver.css`、`gold.css` は読み込まない）。
- スタイル：`src/styles/gold-v2.css`（`GoldV2Layout` 以外から読み込まない）。クラス名はすべて `g2-` で始めます（共通の `form-support.css` が `.btn` などを持つため）。
- 動き：`src/scripts/gold-v2.ts`（メニュー、「What we buy」の前へ・次へボタン、追従バー）。自動で動くものはありません。共通の `main.ts`（電話・予約ボタン、FAQの計測、フォーム）も動きます。
- 文言：meta・フォーム文言・売買の流れの文は `src/content/lps/gold-v2.ts`。それ以外の見出し・本文は `gold-v2.astro` に直接書いてあります。
- 問い合わせフォームは、全LP共通の `ContactForm` です。見た目は `gold-v2.css` の `[data-lp='gold-v2']` ブロック（`--cf-*` 変数）で、Figma の茶色と白に合わせています。
- 電話・住所・登録番号・OCCC・グループ名は `company.ts` から出します。フッターには、Privacy、Terms、Do not sell or share の3つのリンクを置きます。

## 色・書体（`gold-v2.css` の `:root`）
Figma の画面から色を読み取りました。**チャコール `#2E2E3A`** が主役です（改修A案の茶色 `#382C11` を替えた）。

| 変数 | 値 | 用途 |
|---|---|---|
| `--ink` | `#2E2E3A` | 見出し、本文の濃い色、ボタン、エリアのカード、追従バー、ヒーローの下・会社・申込みの背景 |
| `--gold` | `#C9A86A` | ヒーローのボタン、カードの枠、手順の番号、下線 |
| `--cream` | `#FBF7F0` | 手順のカード、安心・FAQの背景 |
| `--foot` | `#EEEEEE` | フッターの背景 |
| `--text` | `#4A4A55` | 本文 |
| `--sand` | `#EAE1CD` | 写真が読み込まれるまでの背景 |
| `--serif` / `--sans` | Instrument Serif / Open Sans | 見出し / 本文（`/gold` と同じ自前ホスト） |

A 案からの違い：ヒーローの下は、クリームへ薄くなる代わりに、チャコールへ濃くなる（その上の文字・アイコンは白）。「Who we are」と申込みの背景は、金色→チャコール（金色の上の白い文字より、読みやすい）。フッターの背景は、クリーム→薄いグレー。

## 写真
- **会社と手順の5枚は、Figma の改修B案から書き出した写真**です（2026-11-28 に差し替え。各枠の2倍の大きさで、すでに枠の形に切ってあるため、`object-position` は付けません）。
- ヒーローと、品目のカード7枚は、`/gold` で使っている画像と同じものです。`/gold` とは切り離すため、`public/images/gold-v2/` にコピーして使います。Figma から新しく書き出した写真が届いたら、同じ名前のファイルを差し替えるだけで済みます。

| `data-slot` | 場所 | ファイル | 書き出しの大きさ（表示サイズの2倍） |
|---|---|---|---|
| `hero` | ヒーローの背景（下はチャコールへ濃くなる） | `hero-gold.webp`（`hero-gold-780.webp` も） | 幅いっぱい × 480px |
| `how-1` 〜 `how-4` | 手順の写真（電話、玄関、はかり、握手） | `S1.webp` 〜 `S4.webp` | 680 × 320（表示 340 × 160） |
| `company` | Who we are（オフィスの写真） | `company-office.webp` | 684 × 385（表示 342 × 192） |
| `item-chains`、`item-rings`、`item-earrings`、`item-broken`、`item-gold`、`item-watches`、`item-silver` | 品目のカード | `G1`、`G2`、`G3`、`G4`、`G5`、`P5`、`P1`（`.webp`） | 224 × 224 |

- 各枠は、`<figure class="g2-photo" data-slot="…">` の中の `<img>` です（`alt`、`width`、`height`つき。ヒーロー以外は `loading="lazy"`）。
- Figma から書き出す場合は、WebP で、上の大きさにします。
- `company`（オフィスの写真）は、使用許諾の確認が必要です（2026-11-28 に、確認済みとの連絡あり）。
- 手順の写真は生成画像のため、フッターの「Images are for illustration.」を残します。

## 公開前に確認が必要なもの
- 申込み後の連絡までの営業日数（今は日数を約束しない文。`gold-v2.ts` の `// TODO:`）。Figma も日数を書いていません。
- 買取できる品目の一覧（Figma のカードは、チェーン、指輪、イヤリング、壊れたもの、時計、スターリングシルバー）。
- 訪問までの日数、保険の表記（今は載せていません）。
- 「Do I need an ID?」の答え（今は `/gold` と同じ「売る場合は、はい。テキサス州法で、顔写真つきのIDの確認が必要」）。
- 共通フォームの SMS 同意文は、共通の最新版です。Figma の画面にある文より長くなります。
- OG 画像は、`/gold` と同じ仮のもの（`og-gold.jpg`）です。

## 編集のルール
- gold-v2 の見た目の変更は、`gold-v2.css` と `gold-v2.astro` の中だけで行い、他のLPのスタイルに影響させない。
- 共通のCSS（`tokens.css`、`form-support.css`、`contact-form.css`）を変えたときは、すべてのLPを確認する。
