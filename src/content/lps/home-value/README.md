# Home Value LP

公開前の初期実装。英語コピーは米国向け。40〜60歳の、使っていない持ち物をまとめて整理したい人を想定します。

## 構成の判断
既存のAstro /[slug] ルートとコンテンツ登録方式を利用し、/home-value を追加します。apps/ や別リポジトリは作りません。
このディレクトリの index.ts がLP固有の文言・セクション順を管理し、src/styles/home-value.css が新しい配色と文字組みを限定適用します。

## ページ順
Hero → 身近な持ち物への共感 → カテゴリー → 査定してから選ぶ → 仮の相談例 → 訪問査定の流れ → FAQ → 最終相談導線 → 会社情報。

## 共通化
フォームの共通文言は既存 downsizing.form を再利用し、品目・相談時期・自由記入の例を上書きします。
既存の電話CTA、FAQ、フォーム検証、計測を再利用します。訪問の流れは既存型に合わせた4段階です。

## デザインの初期対応
ブランドグリーン #01472F、クリーム背景、パステルカード、大きな見出し、丸いボタン。
DM Sans は未同梱のため、仕様のOSフォントへフォールバックします。
ヒーロー写真とOG画像は仮。カテゴリー写真は次の制作工程で追加します。
参照会話の生成画像自体は取得できていないため、画像を取得・承認後に public/images/home-value/ に配置してください。

## 公開前に確定する項目
- 正式なロゴ・ヒーロー・カテゴリー・OG写真と利用権
- 会社情報、電話、受付時間、対応地域、取扱品、費用、訪問条件
- フォーム送信先（現在は既存のデモ用スタブ）
- プライバシー等のリンク、公開ドメイン、計測設定

npm run todos でコンテンツ内の未確定情報を確認できます。既存 README.md の公開前項目も適用されます。
